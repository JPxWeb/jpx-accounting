# Kapitas-replacement readiness — capability matrix & build plan (2026-08-20)

**Goal**: a real Swedish micro-AB (kontantmetoden/bokslutsmetoden, helårsmoms, broken fiscal year 0901–0831 with an irregular first year, EU reverse-charge service purchases, non-EU B2B service revenue, owner-paid utlägg) runs its **full bookkeeping and statutory reporting in this product** instead of Kapitas.

**Method**: 16-agent verification workflow (6 requirement-domain code audits → 10 adversarial refutations of every "impossible" verdict), all findings cited to file:line. 29 blockers claimed; **8 refuted, the rest confirmed**. This doc is the synthesis; raw statutory research is in `docs/findings.md` (2026-08-20 entry).

## Headline verdict

**Everything is bookable today, but only via SIE-file workarounds; the VAT return and the operational setup are the real blockers.**

The refute pass established that `POST /api/imports/sie` (+ the Capture screen's "Importera SIE-fil" button) is a **general-purpose posting path**, not just a migration tool: `planSieImport` (`packages/domain/src/store.ts:170-259`) accepts any balanced N-line voucher on any account number (CoA membership is a display-name lookup, never a gate — `classifyAccountNumber` first-digit fallback covers statements), with no bank-leg/VAT-leg/3-line constraints. Utlägg to 2899, revenue credit 3xxx, prelskatt 2518/1630, avskrivningar 7832/1229, periodiseringsfond 8811/2126, resultatdisposition 2091/2099, and rättelse-vouchers are all postable **today** by authoring a small SIE 4I snippet. That is a power-user workaround, not a product answer — but it un-blocks a technical founder immediately.

## Prioritized build plan vs the real deadlines

Deadlines (dogfood company, FY1 ends 2026-08-31): helårsmoms **2026-10-26** if EU-handel (else 2027-04-12); årsstämma ≤2027-02-28; årsredovisning ≤2027-03-31; INK2 ≤2027-04-01.

- **P0 — before FY2 go-live (2026-09-01)**: G9 ops (durable normal-mode instance + backup script) — _nothing else is a true go-live blocker because the SIE-snippet workaround covers all posting shapes interim_. Optionally the S-sized parts of G11 + bulk-capture retry.
- **P1 — this autumn (before/around the moms deadline + steady FY2 use)**: G1 (VAT boxes — the single biggest correctness gap), G2 (manual journal entry — kills the workaround), G6 (calendar truth), plus CoA year-end accounts (2899, 2614/2645/2647, 1229, 2126/8811, 2518). Corpus fixes from findings.md ship with G6.
- **P2 — close season (early 2027)**: G3 (evidence attach), G4 (SIE export for årsredovisning handoff), G5, G7 (close engine/period lock/correction), G8, G12.
- **P3 — hardening**: G10 (WORM), activity-feed collapse.

**FY1 recommendation unchanged**: close FY1 from the Kapitas SIE4 export via an external årsredovisning/INK2 tool (the product will not generate K2 statements/SRU this season); file the FY1 helårsmoms from Kapitas's momsrapport. Import FY1 into this product for continuity and run FY2 here from day 1.
